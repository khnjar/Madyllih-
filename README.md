# Madyllih Web

نسخة ويب حديثة من الموسوعة الطبية العربية، مبنية على فكرة المشروع الأصلي Android ولكن في قالب ويب احترافي يعتمد على أحدث التقنيات.

## التقنيات
- Next.js 15
- React + TypeScript
- Tailwind CSS
- Gemini API

## التشغيل
```bash
npm install
npm run dev
```

## متغيرات البيئة
```bash
GEMINI_API_KEY=your_key_here
```
